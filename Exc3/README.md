# Задание 3

## Технический радар

Технический радар лежит в директории `tech_radar` в текущей директории.
Для запуска радара необходимо выполнить команды, указанные ниже.
Указанные ниже команды работают для Node.js версии 23.8.0.

- Установка зависимостей:

```sh
npm install
```

- Сборка проекта:

```sh
npm run build
```

- Запуск приложения:

```sh
npm run serve 
```
