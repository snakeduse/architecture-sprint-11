# Описание задания 2

## Домены системы "Будущее 2.0"

Ниже выделяются следующие доменные области для системы "Будущее 2.0":

- **Здравоохранение** (медицинский домен) - Охватывает сервисы по обработке и хранение медицинских данных и передачу событий, связанных с этими данными. Так же в этот домен входят ИИ-сервисы;
- **Финансы/финтех** (банкинг) - Охватывает сервисы по управление финансовыми операциями;
- **Домен аналитики** - Аналитика и визуализация данных, создание различных отчетов. Централизует работу с данными. В него входят компоненты Data Lakehouse, BI-система,портал самообслуживания;
- **Управление** - Охватывает внутренние процессы, не связанные напрямую с аналитикой. В домен входят серисы, связанные с управление клиниками, персоналом, инвентаризацией и т.д.;
- **Администрирование** - Домен охватывает управление IT-инфраструктурой и безопасностью, чтобы упростить аудит и мониторинг;
- **Интеграционный домен** - Включает в себя шину данных, которая позволяет убрать прямую зависимость между компонентами системы и асинхронно обмениваться данными.

Такое разбиение на домены позволит сделать компоненты системы более независимыми друг от друга, что повышает надежность, безопасность, упрощает дальнейшее развитие компонентов системы и упрощает масштабируемость различных компонентов системы.
